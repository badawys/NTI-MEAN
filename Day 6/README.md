# Day 6 — Express and TypeScript

Day 6 introduces the backend HTTP layer used by the MEAN stack. The available
example starts a small Express server written in TypeScript and demonstrates
how a request reaches a route handler and becomes a JSON response.

## Available material

- [Express session demo](express-js-session-demo/README.md)

## Learning outcomes

After completing the example, you should be able to:

- create an Express application with TypeScript;
- import Express request and response types;
- register `GET` routes;
- read a query parameter from `request.query`;
- return JSON from a route handler; and
- run a TypeScript server in development and production-style modes.

## Start the example

```bash
cd "Day 6/express-js-session-demo"
npm install
npm run dev
```

The server listens on `http://localhost:3000`.

All material is student-facing and uses fictional Codes Training Center data.
